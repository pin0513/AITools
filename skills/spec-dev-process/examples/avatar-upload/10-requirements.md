# 會員上傳大頭貼 — 需求

## 需求清單
| ID | 需求 | 型態 | 來源錨點 | AC |
|---|---|---|---|---|
| REQ-001 | 會員上傳大頭貼(jpg/png,≤ 5MB) | functional, integration | PM§3.1 | AC-001-1, AC-001-2, AC-001-3 |
| REQ-002 | 上傳前可裁切為正方形(最小 200px) | functional, domain_rich | PM§3.2 | AC-002-1 |
| REQ-003 | 個人頁顯示大頭貼,無圖顯示預設圖 | functional | PM§3.3 | AC-003-1 |

## 驗收條件
```gherkin
# AC-001-1 成功上傳
Given 已登入會員,選擇 3MB 的 jpg
When 送出上傳
Then 回應 200 並回傳頭像 URL,個人頁顯示新頭像

# AC-001-2 檔案過大
Given 已登入會員,選擇 6MB 的 png
When 送出上傳
Then 回應 400 AVATAR_TOO_LARGE,舊頭像不變

# AC-001-3 儲存服務失敗
Given Blob 儲存服務逾時
When 送出上傳
Then 回應 503,舊頭像不變,記錄警報

# AC-002-1 裁切結果
Given 選擇 1200x800 圖片並框選 600x600
When 確認裁切
Then 送出的圖片為 600x600;框選小於 200x200 時不可確認

# AC-003-1 顯示
Given 會員沒有上傳過頭像
When 開啟個人頁
Then 顯示預設圖
```
