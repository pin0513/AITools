# 會員點數兌換 (PM spec)

## 1 背景與目標
會員累積點數卻無法線上兌換。目標:線上兌換獎品,並維持可靠的點數帳本。

## 2 使用者與情境
會員:想兌換獎品並查看點數交易。系統:讓舊點數到期。

## 3 功能需求
### 3.1 點數帳戶點數足夠時會員可兌換獎品
點數帳戶餘額足夠時,會員可以兌換獎品。兌換單初始為待兌換,扣點記為一筆點數交易,由獎品供應商出貨。

### 3.2 點數 12 個月後到期
12 個月未使用的點數會到期。系統每月排程寫一筆到期點數交易,並扣減點數帳戶餘額。

### 3.3 會員可查看點數交易
會員可以查看每筆點數交易,含日期、類型與點數。

## 4 非功能需求
即使並行兌換,點數帳戶餘額也不得為負。

## 5 驗收條件
- 餘額足夠 → 會員兌換獎品 → 建立兌換單並呼叫獎品供應商
- 餘額不足 → 會員兌換獎品 → 回應 422 INSUFFICIENT_POINTS,不扣點
- 點數於 13 個月前取得 → 每月排程執行 → 寫入到期點數交易,餘額減少
- 會員有點數交易 → 會員開啟紀錄 → 每筆點數交易顯示日期、類型、點數
