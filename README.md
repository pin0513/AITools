# AI Tools

通用 AI 工具與方法論集合 - Claude Code Skills 工具箱。

## 📦 包含的工具分類

### 🛠️ 開發團隊工具 (7 個)
- `dev-team-pm` - Product Manager 角色
- `dev-team-ba` - Business Analyst 角色
- `dev-team-architect` - 架構師角色
- `dev-team-qa` - QA Lead 角色
- `dev-team-tech-lead` - Tech Lead 角色
- `dev-team-scrum-master` - Scrum Master 角色
- `spec-dev-process` - PM spec → RD spec 轉換工作流程(可攜套件:方法論路由、C4/UML、B1–B8 技術邊界機械核對、一頁核對面板;零相依 CLI)

### 🤝 團隊協作工具 (7 個)
- `team-maker` - 團隊製作器
- `team-deployment` - 團隊部署工具
- `team-topology-analysis` - 團隊拓撲分析
- `granularity-calibration` - 粒度校準
- `quality-validation` - 品質驗證
- `role-decomposition` - 角色分解
- `structured-interview` - 結構化訪談

### 🔧 通用工具 (6 個)
- `dopeman` - 環境管理秘書
- `Gemini-GenImage` - Gemini AI 圖片生成
- `jira` - Jira 整合工具
- `use-jira-rest-api` - Jira REST API 工具
- `teams-notify` - Teams 通知工具
- `ado-code-review` - Azure DevOps Code Review

### 📐 方法論 (10 個)
- `prompt-optimization` - 提示詞優化
- `md-generation-standard` - Markdown 生成標準
- `avoid-ai-article` - 避免 AI 味寫作
- `user-story-mastery` - User Story 拆解
- `qa-testcase-write-guideline` - QA 測試案例設計
- `continuous-learning-v2` - 持續學習系統
- `work-audit-inspector` - 工作查核審察
- `market-research` - 市場研究
- `product-research` - 產品研究
- `industry-research` - 產業研究

### 🔬 研究工具 (5 個)
- `academic-research` - 學術研究
- `tw-stock-survey` - 台股研究
- 其他研究相關工具

## 🚀 安裝

### 方法 1: 符號連結（推薦）

```bash
# 連結整個 skills 目錄
ln -s ~/AgentProjects/AITools/skills/* ~/.claude/skills/
```

### 方法 2: 選擇性安裝

```bash
# 只安裝需要的 skills
ln -s ~/AgentProjects/AITools/skills/team-maker ~/.claude/skills/
ln -s ~/AgentProjects/AITools/skills/dopeman ~/.claude/skills/
```
